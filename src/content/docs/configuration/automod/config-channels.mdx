Vous pouvez **configurer les salons** dans lesquels les messages ne seront jamais vérifiés par la protection AutoMod personnalisée.

```
/paramètres-automod
```

Depuis le panneau affiché, cliquez sur le bouton **Gérer les salons**. La sélection se fait via un menu multi choix. Vous pouvez ajouter jusqu'à **25 salons textuels** exemptés, la limite du composant de sélection Discord. Un bouton **Retour** permet de revenir au panneau principal.

<Aside type="tip" title="Préremplissage automatique">
  La toute première fois que vous ouvrez ce panneau, la liste des salons exemptés est automatiquement préremplie à partir des salons déjà configurés pour le [filtre anti insultes](/configuration/swear/config-channels), s'il y en a. Il s'agit d'une copie ponctuelle réalisée une seule fois : les deux listes évoluent ensuite indépendamment, et vous pouvez modifier librement la sélection AutoMod sans affecter celle du filtre anti insultes.
</Aside>

<Aside type="note" title="Par défaut">
  Aucun salon n'est exempté par défaut si le filtre anti insultes n'en a lui même aucun de configuré, ce qui signifie que la protection AutoMod s'applique alors dans tous les salons de votre serveur.
</Aside>

Quand la règle AutoMod est déjà active, toute modification des salons exemptés est appliquée immédiatement sur Discord, sans avoir besoin de désactiver puis réactiver la protection.

## Permission

Permission par défaut : **Gérer le serveur**.
