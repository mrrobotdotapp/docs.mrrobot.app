Voici toutes les commandes de Mr. Robøt. Cliquez sur une commande pour ouvrir sa page détaillée.

Sur Discord, tapez `/` dans la zone de message pour les retrouver, ou utilisez [`/aide`](/utility/help/) pour afficher le panneau d'aide du robot.

:::note
La colonne **Permission** indique la permission requise par défaut. Un administrateur du serveur peut la modifier dans **Paramètres du serveur › Intégrations › Mr. Robøt**. Voir aussi les [permissions du robot](/getting-started/permissions/).
:::

Dans la colonne **Commande**, `<option>` est obligatoire et `[option]` est facultative.
